## Projects

### 1. 채용 플랫폼 사용자 행동 분석

- 핵심 전환 지표를 재정의하고 개선 전략 도출

### 2. 공유 오피스 무료 체험 데이터 분석
- 공유 오피스 체험 데이터를 기반으로 예측 모델을 설계하여 유료 전환 주요 요인 도출
- 예측 모델(머신러닝)을 활용하여 전환 가능성이 높은 사용자를 식별
- 피처 중요도 분석을 통해 큰 영향을 끼친 요인들을 활용하여 전략 제안
- Python, Tableau

---

### 3. 10대 익명 투표 SNS 앱 유저 행동 분석
- 익명 투표 앱 리텐션 개선을 위한 군집별 맞춤 전략 제안
- 핵클 이벤트 로그 기반 유의미한 행동 이벤트 정의
- 퍼널 및 리텐션 분석을 기반으로 4개의 굽집으로 도출하여 각각 맞춤 전략 제안
- Python, SQL, Tableau
